# Vijay Kumar B — Developer Portfolio

A responsive, static portfolio website designed for free GitHub Pages hosting. It needs no paid hosting, backend, database, build step, or API keys.

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
2. Add your latest resume PDF at `assets/resume/Vijay_Kumar_Resume.pdf` (keep that exact filename, or update both download links in `index.html`).
3. Add your GitHub profile URL when ready. LinkedIn is already linked to the profile supplied earlier.
4. Verify employment dates, role titles, project descriptions and certification names against your latest resume. Add certificate verification URLs if available.
5. Optionally replace the VK initials avatar with a professional photo.

## Publish with GitHub Pages (free)

1. Create a **public** GitHub repository named `portfolio` (or any name you prefer).
2. Upload the contents of this folder to the repository root. `index.html` must be at the root, not inside another nested folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. The site URL will be `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`.

For a URL without `/portfolio/`, create a repository named exactly `YOUR-GITHUB-USERNAME.github.io` and upload these same files to its root. Its URL will be `https://YOUR-GITHUB-USERNAME.github.io/`.

## Updating the site

Edit `index.html`, `assets/css/styles.css`, or `assets/js/main.js`, then commit and push the changes. GitHub Pages republishes automatically.

## Important hosting note

This portfolio is intentionally static so it can remain free on GitHub Pages. A backend/API and SQL database are not needed for a job-application portfolio. The contact section uses email and LinkedIn links instead of a server-side contact form.
