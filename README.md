# Vijay Kumar B — Angular Portfolio

Angular 20 standalone-component version of the supplied portfolio.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:4200`.

## Build
Run `npm run build`.

The page is composed from standalone components in `src/app/components`.
Images and resume are stored in `src/assets`.
